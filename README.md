# prison_management_system
Java Swing application for prison management and simulation.

This project is a Java Swing application that simulates prison management.  
It includes detainees, visitors, and penitentiary staff, with interactive actions such as patrol, visit, release, and courtyard movements.

## Key Features
- Group detainees by sentence duration
- Assign detainees to cells
- Animate actions: patrol, visit, release, enter/exit courtyard
- GUI with interactive buttons

## Purpose
This project was developed as part of a study exercise to practice Java Swing, object-oriented programming, and animation in GUI applications.
